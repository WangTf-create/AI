# 文案治理 SPEC（governance）

- **状态**：governance（持续生效）
- **更新于**：2026-06-10

## 品牌称谓

- 站点主品牌名：**花旗银行**（`h1`、`<title>`、logo 旁文字、页脚版权一致）。
- 语气：专业金融感 + 公众号传播力，避免低俗、夸张承诺收益、违反广告法的表述。

## Slogan 口径

- **当前生效 slogan**：普通人攒钱，高手**让钱自己去飞**
- 结构要求：对比句（大众行为 vs 高手行为）+ 动词画面感（「飞」与首页翅膀视觉呼应）。
- 高亮规则：slogan 中核心短语用 `<em>` 包裹，样式为金色 `#ffd700`（见 `index.html` `.hero .tagline em`）。
- 变更 slogan 时：同步更新 `implemented/branding/BRANDING_SPEC.md` 与 `index.html` 中 `.tagline` 文案。
