## 1. 背景 / 目标

当前顶栏四个导航项与「了解更多」按钮仍为 `href="#"` 占位；「立即开户」已跳转 Google 官网。本 spec 规划其余子页面，使 demo 从单页扩展为多页静态站（仍保持无构建、纯静态）。

## 2. 契约（规划）

| 导航文案 | 建议路径 | 页面主题 |
|---|---|---|
| 个人银行 | `personal.html` | 储蓄、信用卡、日常理财入口 |
| 企业金融 | `corporate.html` | 对公账户、贸易融资简介 |
| 投资理财 | `investment.html` | 基金、保险、资产配置简介 |
| 关于我们 | `about.html` | 品牌故事、全球网络 |

### CTA 状态

| 按钮 | 跳转 | 状态 |
|---|---|---|
| 立即开户 | `https://www.google.com/` | 已落地（外链，新标签页） |
| 了解更多 | `about.html`（规划） | planned |

### 不变量（落地后）

- 各子页面复用首页品牌色与顶栏结构（可后续抽公共片段，但当前仍优先静态简单）。
- 子页面 `<title>` 格式：`{栏目名} - 花旗银行`。

## 3. 验收标准

- [ ] 四个导航链接指向真实 HTML 文件，非 `#`
- [ ] 每个子页面可独立在浏览器打开
- [ ] 顶栏品牌与首页一致
- [ ] 本 spec 迁入 `implemented/navigation/` 并更新 README
